# 🧛 Supernatural Add-on

Um addon inspirado na série **Supernatural** para Minecraft Bedrock 1.20.80 com sistema de missões, raças de caçadores e um diário interativo.

---

## 📋 Características Principais

### 🎯 Sistema de Missões
- **22 Missões** da Temporada 1
- Progressão linear com desbloqueio de conteúdo
- Rastreamento de progresso via scoreboard

### 🧬 3 Raças de Caçadores
1. **Caçador Humano** 👤
   - Título: "O Investigador"
   - Nível: 1

2. **Demônio Caçador** 😈
   - Título: "O Possuído"
   - Nível: 2

3. **Anjo Caçador** ✨
   - Título: "O Abençoado"
   - Nível: 3

### 📖 Diário do Caçador (5 Páginas)
1. **Capa** — Status geral
2. **Missões** — Lista de 22 missões
3. **Raças** — Informações sobre raças
4. **Temporadas** — T1 desbloqueada
5. **Coordenadas** — Locais desbloqueados

---

## 🚀 Instalação

- Minecraft Bedrock 1.20.80+
- Script API 1.10.0 habilitada

---

## 📖 Comandos

- `/diario` — Abre o Diário
- `/diario info` — Informações do addon
- `/diario reset` — Reseta progresso (em desenvolvimento)

---

## 📊 Arquitetura

- `main.js` — Orquestrador principal
- `constants.js` — Dados (missões, raças)
- `player_progress.js` — Sistema de progresso
- `diario_ui.js` — Interface do Diário
